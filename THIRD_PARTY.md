# Bundled Starlight icons

`src/components/starlight/icons.generated.ts` contains the static BuiltInIcons
and FileIcons SVG strings from withastro/starlight revision
`dba20640bac11cbf3a9eb69ae3816b380fb6e3e8`. Sources:

- packages/starlight/src/components-internals/Icons.ts
- packages/starlight/src/user-components/file-tree-icons.ts

The paths are data only. No upstream Astro implementation is executed.
Unknown icon names use a fixed question-mark fallback.
